This directory holds all self-generated SVG assets.

Files ending in .svg are generated by Python scripts in ../scripts/.
Do not edit them by hand — your changes will be overwritten.

Generated by:
  scripts/gen_portrait.py  → portrait.svg
  scripts/gen_headings.py  → hd-*.svg
  scripts/gen_stats.py     → stats.svg  streak.svg  langs.svg  year.svg
  scripts/gen_projects.py  → projects.svg

To regenerate locally:
  export GITHUB_TOKEN=<your_token>
  export GH_LOGIN=Fawadullah15
  python scripts/gen_stats.py
  python scripts/gen_projects.py
